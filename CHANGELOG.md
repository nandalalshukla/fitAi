# Changelog

All notable changes to FormFit. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0 — first release candidate

- On-device pose estimation (BlazePose via TFLite) with live skeleton, 11 camera-tracked exercises,
  rep counting, form rules, quality scores and an exercise classifier (free mode).
- Voice coach with priority speech queue and music ducking.
- Offline-first data with Supabase sync, guest mode, email/Google/Apple sign-in, export and
  account deletion.
- Onboarding, Today, plan library, workout player (camera or manual), rest timer, summary,
  progress charts, exercise library, settings and reminders.
- 11 researched plans and 54 exercises with original animated demos.
- Crash reporting and analytics (opt-out, scrubbed), accessibility audit, security review.
