# Accessibility

Target: WCAG 2.1 AA-equivalent on iOS and Android.

| Area           | How                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Screen readers | Every tappable element has a label or visible text — enforced by `src/features/shell/accessibility.test.tsx` across all main screens and onboarding. Headers use `accessibilityRole="header"`; selection uses `accessibilityState`; live regions announce form cues, rest timers, offline state and errors. Decorative visuals (confetti, skeleton, cue labels) are hidden from screen readers. |
| Voice-only use | The voice coach counts reps, corrects form, announces rests and the next exercise; sets complete automatically at the target, so a workout can run hands-free.                                                                                                                                                                                                                                  |
| Contrast       | Colour tokens are checked for AA in `src/ui/theme/__tests__` (`contrast.ts`). Meaning is never conveyed by colour alone (icons + text on form banners, check marks on selected chips/cards).                                                                                                                                                                                                    |
| Dynamic type   | All text uses the `Text` component; body text scales up to 1.6×, giant counters are capped so they still fit. Layouts wrap rather than truncate.                                                                                                                                                                                                                                                |
| Touch targets  | `hitTarget` token (≥ 48 dp) for buttons, chips and icon buttons.                                                                                                                                                                                                                                                                                                                                |
| Motion         | `useMotion().reduceMotion`: entrances become fades, confetti and pulses are skipped, exercise demos show static step positions with previous/next step buttons.                                                                                                                                                                                                                                 |
| Haptics        | Rep, set-complete and warning haptics complement (never replace) visual/voice feedback.                                                                                                                                                                                                                                                                                                         |
